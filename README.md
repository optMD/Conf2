# apt-depgraph

Инструмент визуализации графа зависимостей пакета Ubuntu (формат apt).
Получение зависимостей выполнено без менеджеров пакетов и сторонних
библиотек.

## Общее описание

Инструмент строит граф зависимостей заданного пакета Ubuntu и сохраняет
его изображение в PNG (через Graphviz). Источником зависимостей служит
файл `Packages.gz` репозитория Ubuntu или тестовый файл описания графа.

Проект находится в разработке (этап 1).

## Настройки

| Параметр | Значение |
|---|---|
| `package` | имя анализируемого пакета |
| `source` | URL файла `Packages.gz` или путь к тестовому файлу |
| `--mode {repo,test}` | `repo` — реальный репозиторий, `test` — граф из файла |
| `-o, --output FILE` | имя PNG-файла (по умолчанию `graph.png`) |
| `--direct` | вывести только прямые зависимости |
| `--reverse` | вывести обратные зависимости (кто зависит от пакета) |

## Сборка и тесты

```sh
./run.sh build   # собрать компоненты
./run.sh test    # запустить тесты
```

## Примеры использования

```sh
./run.sh curl https://archive.ubuntu.com/ubuntu/dists/noble/main/binary-amd64/Packages.gz
./run.sh A tests/data/cycle.txt --mode test -o graph.png
```
